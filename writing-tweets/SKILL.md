# Writing Tweets Skill

## When to use this skill
- When the user wants to draft a tweet for X.com.
- When the user provides a topic for a social media post.
- When the user specifically asks for "clickbaity" or "CTA-friendly" short content.

## Workflow
1. [ ] **Ask for Topic**: If the user hasn't provided a topic, ask for it.
2. [ ] **Deep Research**: Use the `search_web` tool to find current trends, interesting facts, or controversial angles related to the topic.
3. [ ] **Analyze CTA Opportunities**: Identify what action the user might want readers to take (e.g., click a link, reply, retweet).
4. [ ] **Drafting**: Create multiple versions of the tweet that are clickbaity and include a strong CTA.
5. [ ] **Validation**: Ensure the final tweet is under 280 characters and concise.

## Instructions
- **Length Constraint**: All generated tweets MUST be 280 characters or fewer. Include the character count in your proposal.
- **Clickbait Techniques**: Use punchy hooks, emotional triggers, or curiosity gaps (e.g., "The one thing...", "Stop doing X...").
- **CTA Format**: Always include a clear Call to Action at the end.
- **Tone**: High-energy, engaging, and professional.
- **Research focus**: Find 1-2 surprising facts or data points to anchor the tweet.
