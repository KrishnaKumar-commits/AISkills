# Creating Resumes Skill

## When to use this skill
- When the user wants to build a new resume from scratch.
- When the user needs to update specific sections of their CV.
- When the user wants to ensure their resume follows a professional structure.

## Workflow
1. [ ] **Gather Information**: Ask the user for their:
    - Personal Details (Name, Contact, LinkedIn)
    - Professional Summary
    - Core Skills (Technical & Soft)
    - Work Experience (Company, Role, Dates, Key Achievements)
    - Educational Background (Institution, Degree, Years)
    - Languages Known
2. [ ] **Structure Draft**: Organize the data into the mandatory sequence: Personal Details > Summary > Skills > Experience > Education > Languages.
3. [ ] **Optimization**: Use action verbs and quantifiable results for work experience to make it ATS-friendly.
4. [ ] **Review**: Present the draft for user feedback.
5. [ ] **Formatting**: Provide the final resume in a clean Markdown or plain text format.

## Instructions
- **Logical Flow**: strictly follow the order: Personal Details -> Summary -> Skills -> Work Experience -> Education -> Languages.
- **ATS Friendly**: Focus on keywords related to the user's industry. Use the `search_web` tool if needed to find trending keywords for a specific role.
- **Conciseness**: Keep the summary punchy (3-4 sentences) and experience points result-oriented.
- **Tone**: Formal and professional.
